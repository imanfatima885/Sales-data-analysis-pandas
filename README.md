# Sales Data Analysis using Python & Pandas

This project demonstrates basic sales data analysis using **Python** and **Pandas**. It performs data exploration, statistical analysis, filtering, aggregation, and sorting on a sales dataset stored in a CSV file.

## Features

- Import and analyze a CSV dataset
- Display the first and last five records
- View dataset information
- Calculate total and average sales
- Identify the product with the highest sales
- Determine the best-selling category
- Filter sales with a total amount greater than 5000
- Sort records by total amount
- Export the analyzed dataset to a new CSV file

## Technologies Used

- Python
- Pandas
